어떻게 분석하나요?

  1. 프레임 추출 — 장면 전환·움직임을 고려한 적응형 샘플링 (시간 순서 유지)
  2. 얼굴 검출·크롭 — 조작 흔적이 집중되는 얼굴 영역만 입력
  3. CNN — ResNet 백본이 프레임의 공간적 아티팩트(경계·질감) 탐지
  4. LSTM — 16프레임 오버랩 시퀀스로 시간적 일관성(깜빡임·표정 전이) 분석

  7. Grad-CAM — 모델이 주목한 영역을 히트맵으로 시각화
